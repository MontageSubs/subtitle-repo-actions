## 解决方法 / How to fix

正确的仓库名应为 / The correct repository name should be:

```
{suggested_repo_name}
```

1. 前往仓库 **Settings** 页面最顶部的仓库名输入框，将仓库名改为上方名称 / Go to the repository name field at the very top of the **Settings** page, and rename it to the name above
2. 直达入口 / Direct link: [此链接 / this link](../../settings)
3. 改名完成后，回到 **[Actions](../../actions/workflows/init.yml)** 页面重新运行 **"初始化 (Initialize)"** 工作流 / After renaming, go back to **[Actions](../../actions/workflows/init.yml)** and re-run the **"初始化 (Initialize)"** workflow

> [!NOTE]
> 改名不会丢失仓库的历史记录、Settings 配置或已有的 secret，比删除重建更省事 / Renaming preserves the repository's history, Settings, and existing secrets — it's simpler than deleting and recreating
