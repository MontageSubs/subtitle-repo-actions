## 🛠️ 解决方法

> [!TIP]
> 正确的仓库名应为：
> ```
> {suggested_repo_name}
> ```

1. 前往仓库 **Settings** 页面最顶部的仓库名输入框，将仓库名改为上方名称
2. 直达入口：[此链接](../../settings)
3. 改名完成后，回到 **[Actions](../../actions/workflows/init.yml)** 页面重新运行 **"初始化 (Initialize)"** 工作流

> [!NOTE]
> 改名不会丢失仓库的历史记录、Settings 配置或已有的 secret，比删除重建更省事

## 🛠️ How to Fix

> [!TIP]
> The correct repository name should be:
> ```
> {suggested_repo_name}
> ```

1. Go to the repository name field at the very top of the **Settings** page, and rename it to the name above
2. Direct link: [this link](../../settings)
3. After renaming, go back to **[Actions](../../actions/workflows/init.yml)** and re-run the **"初始化 (Initialize)"** workflow

> [!NOTE]
> Renaming preserves the repository's history, Settings, and existing secrets — it's simpler than deleting and recreating
