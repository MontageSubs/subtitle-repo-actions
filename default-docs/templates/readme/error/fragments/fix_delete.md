## 解决方法

1. **重新创建**：请删除本仓库，并使用符合 `英文片名_年份` 格式的名称重新创建。
2. **删除仓库**：点击 **[此链接](../../settings#danger-zone)**（或手动前往 **Settings --> General --> Danger Zone**）进入 Danger Zone。
3. **确认删除**：点击 **Delete this repository**，并按提示输入仓库全名以确认删除。
