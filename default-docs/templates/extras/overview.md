# 花絮与番外内容 / Extras

本目录收录该版次下的花絮、预告片等番外内容的字幕制作，每个子目录对应一项独立内容，结构与正片版次一致。

## 下方会有哪些子目录

每新增一项番外内容即新增一个以标题简称命名的子目录（如 `trailer`、`deleted-scene-1`），目录内的 `README.md` 说明具体内容。

## 新增番外内容

维护者可通过 [Actions](../../../../../actions/workflows/add-extra.yml) 中的 **新增 Extra (Add Extra)** workflow 手动触发创建。
