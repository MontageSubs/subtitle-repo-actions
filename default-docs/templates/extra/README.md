# {extra_title}

本目录收录该番外内容的字幕制作，结构与正片版次一致。

## 下方会有哪些子目录

字幕的翻译、制作与生成全部发生在 [`work/`](./work/) 目录下，其中又分三个子目录：

- [`work/source/`](./work/source/) —— 官方原始底本，只读，不改动
- [`work/authored/`](./work/authored/) —— 翻译、校对、时间轴、特效持续打磨的地方
- [`work/generated/`](./work/generated/) —— 自动化产出的最终字幕，随时可被重跑覆盖

进入 [`work/`](./work/) 查看完整说明。
